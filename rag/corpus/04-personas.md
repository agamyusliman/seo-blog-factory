# Personas (untuk angle artikel) — F&B ONLY

> **Scope produk saat ini: F&B saja.** Jangan tulis artikel seolah retail/minimarket/salon/laundry/barbershop sudah jadi target SaaS utama.

## Persona utama

1. **Pemilik gerobak/warung** — omzet harian, QRIS, struk, harga murah → Basic + QRIS
2. **Bazar / pasar malam / stand event** — outdoor, ramai, tutup kas cepat, offline
3. **Lapak kontainer / pinggir jalan tanpa meja** — takeaway, mobile, printer BT
4. **Usaha rumahan / katering / pre-order IG-WA** — katalog online, DP, pickup, QRIS
5. **Cloud kitchen / dapur khusus delivery** — label channel delivery, laporan multi-sumber
6. **Owner cafe / coffee shop** — meja, self-order, shift, theme menu → Pro
7. **Owner restoran / RM** — meja, KDS, split bill, reservasi, PB1 → Pro
8. **Food court / multi-kasir F&B** — shift variance, multi staff, KDS
9. **Bakery / dessert / seblak / camilan** — pre-order, combo, HPP
10. **Franchise / multi-cabang F&B** — dashboard owner, plan per outlet
11. **Enterprise F&B / brand kuliner** — custom POS, white-label → `/enterprise`
12. **Owner belanja perangkat kasir F&B** — printer thermal → `/toko` + `/toko/katalog`

## Geo (home base)

- **Batam**, **Tanjungpinang**, **Bintan**, **Kepri** — konten lokal + demo
