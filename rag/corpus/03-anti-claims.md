# Anti-claims (JANGAN diklaim di artikel)

## Scope produk (KRITIS — 2026)

- SaaS Kekasir **saat ini fokus F&B** (restoran, cafe, warung, gerobak, katering, cloud kitchen, bakery, food stall, dll.).
- **JANGAN** posisi produk sebagai aplikasi kasir retail minimarket / toko kelontong / fashion.
- **JANGAN** posisi produk sebagai kasir salon, barbershop, laundry, klinik, atau jasa appointment umum.
- **JANGAN** tulis “cocok untuk semua jenis usaha retail dan jasa” sebagai klaim utama.
- Boleh sebut “dirancang untuk usaha kuliner / F&B” dan skala dari gerobak sampai multi-cabang F&B.

## Integrasi & marketplace

- JANGAN klaim integrasi **API otomatis** GoFood / GrabFood / ShopeeFood (order masuk otomatis).
- BOLEH: catat **label** sumber order delivery secara manual di kasir.

## Fitur yang tidak boleh di-overclaim

- Loyalty points / membership “sudah fully live” — default **jangan klaim**.
- Custom role permission bebas — role relatif tetap (kasir/dapur/admin).
- Network printer “full support semua merek” — fokus Bluetooth/USB thermal.
- Firefox/Safari full Web Bluetooth printer — rekomendasikan Chrome/Edge bila sebut print browser.
- Helpdesk artikel DB di dashboard owner — bukan sumber utama.
- WABA / WhatsApp Business API CRM sebagai fitur default POS Basic — secondary only.
- Fitur **appointment / janji temu layanan non-F&B** — **jangan** jadi topik artikel.
- Fitur **inventori retail** (minimarket, multi-barcode toko, repacking ritel) sebagai selling point — **jangan**.
- Stok usaha kuliner yang boleh dibahas: **bahan baku, resep, HPP, biaya bahan**.

## Offline

- BOLEH: kasir tetap catat transaksi offline, sync saat online.
- JANGAN: “semua fitur 100% offline” — QRIS dinamis, KDS realtime, sebagian aksi shift/self-order butuh online.

## Pembayaran

- JANGAN: “QRIS gratis / tanpa MDR”.
- JANGAN sebut brand PG spesifik di copy massal.
- BOLEH: QRIS, e-wallet umum, mitra penyelenggara pembayaran, MDR ~0,7%.

## Harga & legal

- JANGAN pakai Basic Rp50.000 / Pro Rp100.000 (stale).
- WAJIB: Basic **Rp60.000**, Pro **Rp120.000** /bulan; tahunan **Rp576.000** / **Rp1.152.000** (S&K).
- JANGAN janjikan refund langganan bebas / pro-rata (umumnya **non-refundable** — Kebijakan Refund).
- JANGAN janjikan refund QRIS otomatis dari sistem; MDR **tidak** dikembalikan.
- JANGAN anjurkan **surcharge** QRIS ke pelanggan (dilarang).
- JANGAN bilang settlement QRIS selalu **instan hari yang sama** (standar **T+2 hari kerja**).
- Detail: `10-legal-compliance.md` + https://kekasir.id/syarat-ketentuan

## Studi kasus

- JANGAN invent angka omzet merchant fiktif seolah testimonial nyata.
- BOLEH: skenario hipotetis **F&B** yang jelas ditandai sebagai contoh.
- Vertical studi kasus: warung, cafe, resto, katering, gerobak, cloud kitchen, bakery, food court stall — **bukan** ritel/jasa.
