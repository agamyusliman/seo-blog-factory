# Keyword Pendukung SEO (RAG)

Pakai untuk: primary keyword, secondary LSI, H2, meta, internal linking.
Aturan: 1 primary di title+intro+1 H2; secondary natural (2–6x); jangan stuffing.

## Cara pilih keyword per artikel

| Slot | Sumber |
|------|--------|
| primary_kw | dari job / seed title |
| secondary | 4–8 dari cluster kategori + vertical |
| brand soft | Kekasir / aplikasi kasir Kekasir (2–4x max) |
| CTA phrase | dari corpus fitur-cta, bukan keyword spam |

Modifier opsional (variasi title, jangan di-stuff body):
`2026`, `pemula`, `UMKM`, `murah`, `online`, `HP Android`, `multi cabang`, kota (`Batam`, `Jakarta`, `Bandung`, `Surabaya`)

## Frasa H2 siap pakai (template)

- Apa itu {primary_kw}?
- Manfaat {primary_kw} untuk {persona}
- Cara {primary_kw} langkah demi langkah
- Kesalahan umum saat {topic}
- Checklist {topic}
- Contoh kasus {vertical}
- Kapan perlu {fitur / solusi digital}
- Tips memilih {solusi} untuk UMKM
- Kesimpulan dan langkah mulai hari ini

## Meta description pattern

`{Manfaat utama} untuk {persona}. Pelajari {primary_kw}, tips praktis, dan cara mulai dengan aplikasi kasir. Coba gratis 14 hari.`

Panjang target 140–160 karakter.
